3. SECURITY POLICIES

Password Requirements:
- Minimum 12 characters
- Must include uppercase, lowercase, numbers, and symbols
- Must be changed every 90 days
- Never reuse the last 5 passwords

Two-Factor Authentication (2FA):
- Mandatory for all company accounts
- Use Google Authenticator or Authy
- Hardware security keys available on request from IT

VPN Usage:
- Required when accessing company systems outside the office
- Fatinova Technologies uses NordVPN Teams — credentials in your welcome email
- Never connect to public WiFi without VPN

Data Handling:
- No customer data on personal devices
- All sensitive documents must be stored in Google Drive
- Do not share confidential files via personal email
- Report any data breach immediately to security@fatinovatechnologies.com

4. SOFTWARE REQUESTS

To request new software or tools:
1. Submit a request via the IT portal: it.fatinovatechnologies.com
2. Include the tool name, purpose, cost, and number of users
3. IT will review within 3 business days
4. Finance approval required for tools over $500/year

Unauthorized software installation is prohibited and may
result in disciplinary action.
